# UMBFY Package Support

Use this repository for public support, bug reports, feature requests, documentation, and package guidance across the UMBFY ecosystem.

## Report a problem

Use the GitHub issue forms in this repository and include the affected package, package version, Umbraco version, reproduction steps, and safe logs/screenshots.

## Before posting

- Search existing issues first.
- Remove secrets, connection strings, license keys, personal data, and customer-sensitive information.
- Include exact versions where possible.

Start at [docs/README.md](docs/README.md).
