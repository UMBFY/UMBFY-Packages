# General Troubleshooting

When a UMBFY package does not behave as expected:

1. Confirm the exact package version.
2. Confirm the exact Umbraco version.
3. Review package-specific configuration.
4. Check application logs and browser console output.
5. Confirm package migrations/initialization completed.
6. Search existing issues in this repository.
7. Open a support or bug issue with safe diagnostic details.

Never post secrets, credentials, connection strings, license keys, or private customer data in public issues.
