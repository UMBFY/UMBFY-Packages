# Content Guard Configuration

Content Guard configuration is package-specific and should match the released defaults.

Documented policy modes include:

- **Warn** — allow the operation but show dependency risk.
- **RequireConfirmation** — require an explicit editor confirmation before the protected operation continues.
- **Block** — prevent the protected operation when policy conditions are met.

Public configuration should document Safe Delete, Publish Guard, multilingual validation, and any supported index/rebuild settings. Keep configuration examples synchronized with the current release.
