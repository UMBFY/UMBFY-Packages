# Content Guard Troubleshooting

When Content Guard is not behaving as expected:

1. Check the dependency index state in Content Health.
2. Confirm package and Umbraco versions.
3. Review application logs for Content Guard warnings/errors.
4. Confirm the relevant reference type is supported.
5. Rebuild the dependency index if diagnostics indicate it is required.
6. Verify Backoffice permissions for the current user.
7. Search existing issues before opening a new report.

Include safe logs and reproduction steps when reporting an issue.
