# Content Guard Quick Start

1. Install Content Guard.
2. Start Umbraco and wait for dependency-index initialization to complete.
3. Open a content or media item.
4. Use **Where Used** to inspect inbound references.
5. Review **Impact** before changing shared content.
6. Use **Content Health** to review dependency integrity across the visible site scope.
7. Configure **Safe Delete**, **Publish Guard**, and multilingual validation according to your editorial policy.
