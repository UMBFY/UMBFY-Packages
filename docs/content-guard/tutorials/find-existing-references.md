# Tutorial: Find Existing References

1. Open the target content or media item.
2. Open **Where Used**.
3. Review the source items, properties, cultures, and states shown.
4. Use the available navigation action to open an authorized source.
5. Use **Impact** when you need a broader dependency view than direct inbound references.

If Where Used appears incomplete, check the dependency-index state in Content Health and rebuild only when diagnostics indicate it is necessary.
