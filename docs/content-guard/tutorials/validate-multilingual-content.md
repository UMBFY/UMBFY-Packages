# Tutorial: Validate Multilingual Content

1. Open **Content Health** and filter findings by culture where useful.
2. Review missing or unpublished target-language findings.
3. Check whether the target culture exists and is published.
4. Review configured language fallback behavior.
5. Correct the affected content or dependency.
6. Re-check Content Health or Publish Guard before publishing.

Content Guard should not expose restricted culture details to users who are not authorized to view them.
