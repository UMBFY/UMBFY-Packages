# Collaboration FAQ

## Does Collaboration work with multiple Backoffice users?

Yes. The package is designed for realtime awareness across authenticated Backoffice sessions.

## Does it replace Umbraco permissions?

No. Resource visibility remains authorization-aware.

## Does load balancing require extra configuration?

Multi-node deployments may require the package's supported shared realtime/state configuration. See the load-balanced setup guide for the released version.
