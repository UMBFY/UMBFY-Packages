# Contributing to UMBFY Packages

Thank you for helping improve the UMBFY package ecosystem.

## Documentation contributions

- Keep documentation package-specific and task-oriented.
- Prefer examples that work on supported Umbraco versions.
- Do not include customer data, credentials, or private URLs.
- Keep feature names consistent with the package UI.

## Issues

Use the repository issue forms for bugs, features, and support requests.

## Pull requests

Keep changes focused, explain the user impact, and update relevant documentation when behavior changes.
